# Student Portfolio and Academic Management Website

## Project Description
This project is a responsive Student Portfolio and Academic Management Website developed as part of my COS 106 – Introduction to Web Technologies course.

The website showcases my personal profile, educational background, skills, projects, and provides interactive tools for managing academic tasks.

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality

## Website Features
1. Home – Personal introduction and profile.
2. About Me – Educational background, skills, aspirations and hobbies.
3. Projects – Display of completed projects.
4. Academic Planner – Add, complete, filter and delete academic tasks.
5. Calculator – Basic arithmetic operations.
6. Contact – Contact information and form validation.
